How it Works (Simple)

Think of this AI as a Robot Student learning to write names.

1. The "Future-Blind" Reader

The robot reads names one letter at a time. It covers the rest of the word with its hand. It sees "E" and tries to guess what comes next. It cannot cheat and look ahead.

2. The Voting Booth (Logits)

Inside its brain, the robot doesn't just guess one letter. It holds a vote for every possible letter (A-Z). "M" might get 50 votes, while "Z" gets -10 votes.

3. The Teacher (Loss)

We reveal the actual next letter. If the robot guessed wrong, we give it a score (Loss). A high score means "You did bad."

4. The Smart Hiker (Adam Optimizer)

The robot wants to get its error score to zero (the bottom of the valley). It uses a math trick called "Adam" to find the fastest path down the hill, adjusting its brain so it doesn't make the same mistake twice.

5. Showtime (Inference)

Once trained, we take away the answer key. We give it a starting letter, and it uses its trained intuition to dream up new names entirely on its own!

How it Works (Technical)

This is a pure JavaScript implementation of a Decoder-Only Transformer.

1. Tokenization & Embeddings

Input text is converted to integer IDs. We learn two embedding matrices: wte (Token Embeddings) for identity and wpe (Position Embeddings) for order. These are added together.

2. Self-Attention

The core mechanism. Queries (Q), Keys (K), and Values (V) are computed. We calculate softmax(Q @ K.T) to create an attention map, which determines how much the model should focus on past tokens to predict the current one.

3. MLP & Residuals

The attention output passes through a Feed-Forward Network (MLP) with ReLU activation. We use LayerNorm (RMSNorm here) and Residual connections (adding input to output) to stabilize deep learning.

4. Autograd Engine

We implemented a custom Value class that builds a dynamic computation graph. Calling .backward() performs topological sort and reverse-mode automatic differentiation to compute gradients.

5. Optimization

We use Adam (Adaptive Moment Estimation), which tracks first (momentum) and second (variance) moments of gradients to update weights efficiently.
