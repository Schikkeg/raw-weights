# AI & ML Master Playground

> 17 interactive modules covering the full ML fundamentals curriculum — from what machine learning is through neural network architecture, gradient descent, overfitting, and dropout. All in the browser, no setup required.

## Overview

The ML Master Hub is a card-based interactive playground where each card opens a full modal with explanations, interactive visualisers, and adjustable parameters. The hub covers 17 topics organised from basics through advanced neural network concepts, with a searchable card gallery and slide-based navigation within each module.

Inputs include sliders for learning rate, number of hidden neurons, regularisation strength, dropout rate, and more. Outputs include live loss curves, decision boundary plots, weight visualisations, and prediction outputs.

## Key Topics / Sections

The 17 interactive modules:

- **1. What is Machine Learning?** (Basics): Formal definition and ML history — supervised, unsupervised, reinforcement.
- **2. Supervised Learning** (Types): Learning from labelled data — X-to-Y mappings, classification and regression.
- **3. Unsupervised Learning** (Types): Discovering structure in unlabelled data — clustering, dimensionality reduction.
- **4. Linear Regression** (Models): Predicting continuous values with straight lines; interactive fit visualiser.
- **5. The Perceptron** (Neural Networks): Foundation of deep learning — single neuron with weights, bias, and activation.
- **6. Activation Functions** (Neural Networks): Interactive playground for ReLU, sigmoid, tanh, and leaky ReLU — see how each shapes the network's output space.
- **7. Cost Function** (Mathematics): Measuring error using squared error and cross-entropy — the quantity gradient descent minimises.
- **8. Gradient Descent** (Optimizer): Iterative engine for parameter optimisation — adjustable learning rate, live loss trajectory.
- **9. Multiple Features** (Regression): Predicting with multiple inputs — the vectorised form and feature interaction.
- **10. Vectorisation** (Computing): Faster training through NumPy parallel hardware operations.
- **11. Feature Scaling & Engineering** (Tuning): Normalisation, standardisation, and polynomial feature creation for better convergence.
- **12. Polynomial Regression** (Regression): Fitting curves and messy data — the bridge between linear models and neural networks.
- **13. Logistic Regression** (Classification): Binary classification using sigmoid probabilities and decision boundaries.
- **14. Regularisation** (Optimisation): L1/L2 regularisation — solving overfitting with parameter shrinkage.
- **15. Dynamic Architecture** (Neural Networks): Build dense layers and inject real data — interactive network constructor.
- **16. Overfitting & Dropout** (Neural Networks): Force the model to generalise — dropout visualiser showing which nodes are dropped.
- **17. Instructor Whiteboard** (Tools): Freeform interactive graph for answering questions with custom drawn data.
