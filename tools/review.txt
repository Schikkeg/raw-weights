                    <summary class="font-semibold text-gray-800 flex justify-between items-center">
                        How does the "Plato's Cave" analogy explain latent variables?
                        <span class="text-brand-600 transition group-open:rotate-180">▼</span>
                    </summary>
                    <div class="mt-3 text-gray-600 text-sm leading-relaxed border-t border-gray-200 pt-3">
                        In the ancient myth of Plato's Cave, prisoners can only see shadows moving on a wall, which represent the observable data we see in real life, like pixels in an image. The true 3D objects casting those shadows represent the latent variables, which are the underlying, hidden features governing the data distribution. Generative models attempt to extract these hidden explanatory factors just from observing the "shadows".
                    </div>
                </details>

                <details class="group bg-gray-50 border border-gray-200 rounded-lg p-4 cursor-pointer">
                    <summary class="font-semibold text-gray-800 flex justify-between items-center">
                        Why do Variational Autoencoders (VAEs) use the Reparameterization Trick?
                        <span class="text-brand-600 transition group-open:rotate-180">▼</span>
                    </summary>
                    <div class="mt-3 text-gray-600 text-sm leading-relaxed border-t border-gray-200 pt-3">
                        VAEs introduce stochasticity, or randomness, by parameterizing the latent space as a probability distribution defined by a mean and standard deviation. However, this pure randomness breaks the predictable math required for backpropagation, as gradients cannot be passed through a standard sampling layer. The reparameterization trick solves this by isolating the randomness into a separate constant called epsilon, keeping the core calculations predictable and allowing the model to be trained end-to-end.
                    </div>
                </details>

                <details class="group bg-gray-50 border border-gray-200 rounded-lg p-4 cursor-pointer">
                    <summary class="font-semibold text-gray-800 flex justify-between items-center">

                        <span class="text-brand-600 transition group-open:rotate-180">▼</span>
                    </summary>
                    <div class="mt-3 text-gray-600 text-sm leading-relaxed border-t border-gray-200 pt-3">
                        GANs employ two competing neural networks: a Generator (the "forger") and a Discriminator (the "detective"). The generator starts with completely random noise and attempts to transform it into fake data that imitates the real training data. Meanwhile, the discriminator tries to correctly classify whether the data it sees is real or fake. This competing objective forces the generator to continuously improve its fakes until it can completely fool the discriminator.

        function setSandboxState(stateKey, btnElement) {
            document.querySelectorAll('.sandbox-btn').forEach(btn => btn.classList.remove('active'));
            if (btnElement) {
                btnElement.classList.add('active');
            } else {
                document.getElementById('btn-supervised').classList.add('active');
            }

            const data = sandboxStates[stateKey];
            document.getElementById('sandbox-exp-title').innerHTML = data.title;
            document.getElementById('sandbox-exp-text').innerHTML = data.text;
            document.getElementById('sandbox-exp-example').innerHTML = data.example;
            
            document.getElementById('svg-canvas-target').innerHTML = `
                <svg viewBox="0 0 1000 500" preserveAspectRatio="xMidYMid meet" xmlns="http://www.w3.org/2000/svg">
                    ${defsHtml}
                    ${data.svg}
                </svg>
            `;
            
            // Allow DOM to process the new SVG, then force a height recalculation for the slider
            setTimeout(updateSliderHeight, 50);
        }

        window.addEventListener('DOMContentLoaded', () => {
            setSandboxState('supervised', null);
            // Run initial height calc after a brief delay so styles load
            setTimeout(updateSlider, 100);
        });
