My field notes

A GenAcademy session on AG2 introduced me to the framework. I walked in expecting broad strokes — what I got was depth: every concept backed by live playground demos and real production trade-offs. I went into the GitHub repo, official docs, and the playground afterward to build this reference.

Three things that stuck: multi-turn isn't magic, it's recursion on a response object. Middleware and assembly policies look similar but do fundamentally different things — one mutates history, the other only filters what the model sees. And the $2,000 data destruction incident is a reminder that agents do exactly what they're told — the approval gate has to come from you, not the model.

    From the Q&A

    Getting Started
    Is chaining — ask() then another ask() on the reply — supported? ▾
    Yes. The reply object is itself askable — that is the multi-turn pattern. Context is retained automatically across the chain.
    Is the playground free? Account required? ▾
    Free, no account. AG2 powers the LLM. Use only the Beta column — Classic and Beta look similar but differ architecturally enough to cause confusion.
    How do I teach my coding assistant AG2 Beta patterns? ▾
    Run npx skills add ag2ai/ag2-skills. This installs AG2 Beta knowledge into Claude, Cursor, and others — so the assistant reaches for Beta APIs instead of hallucinating Classic patterns.
    What's the relationship between AG2 Beta and classic AutoGen? ▾
    AutoGen (2023, Microsoft Research) was forked by the community into AG2 (2024). AG2 Beta is a from-scratch async rewrite under autogen.beta. Classic patterns (ConversableAgent, group/sequential chat) are replaced entirely. Vasily's advice: focus only on Beta going forward.
    Architecture
    Hub vs A2A — what's the difference? ▾
    Hub = in-org orchestration (audit log, Passport identity, 4 typed channels). A2A = Google's cross-org, cross-framework standard. AG2 supports both. Hub internally; A2A when connecting to agents from other frameworks or companies.
    Is there an identity or trust system for agent networks? ▾
    Partially. Passport verifies identity and prevents unauthorized connections. Audit logs record who sent what. Fine-grained inter-agent trust (what agent A may share with B) is still evolving — no framework has fully solved it.
    Middleware vs assembly policies — what's the difference? ▾
    Middleware changes what happens — HistoryLimiter permanently deletes. Assembly policies change what the model sees — the full event log is preserved, only the assembled context window changes. Same layer, different intent.
    What are the 4 channel types in the Hub? ▾
    Consulting: one Q, one A, auto-closes. Conversation: free-form pair. Discussion: round-robin N agents. Workflow: declarative TransitionGraph with conditions and targets — most used in enterprise.
    Production
    Can I A/B test agent configurations? ▾
    Yes — use your existing A/B framework. Treat the agent as a standard service component and route users to different middleware stacks, prompts, or models the same way you would any backend variant.
    How do token budgets control cost? ▾
    At ~90% of budget, pass the remaining count back and prompt the agent to wrap up. Forces a coherent final answer instead of a silent cutoff. Cheap models can run 20× cheaper — a workflow of cheap calls often matches expensive smart-loop quality.
    What's the right permission model for production agents? ▾
    Read-only: let it run, control spend. Anything that writes, deletes, sends, or charges: require human approval. Vasily Radostev documented a real incident where his own agent destroyed $2,000 of data — no approval gate, full permissions. It did exactly what it was told. The lesson is not hypothetical.
    How does agent-as-judge evaluation work? ▾
    A separate agent scores outputs against defined criteria (conciseness, source quality, topic coverage). Calibrate the judge against real user feedback first — even 100 satisfied/unsatisfied sessions is enough to align it. Then run it at thousands of interactions automatically.
