# From Asset Selectors to Liquid Synthesis: The Bicycle Math of RL

> An interactive deep reinforcement learning playground teaches the continuous policy gradient mathematics behind modern AI — and applies it to the concept of "Liquid Synthesis," a vision for real-time web transformation driven by RL agents.

## Overview

Learning to ride a bicycle is a physical reinforcement learning problem: continuous feedback, continuous adjustment, no discrete rules. The same mathematics — policy gradients, continuous action spaces, and reward shaping — underlies deep RL systems that are now being proposed as the foundation for a new web paradigm: Liquid Synthesis, where web experiences are generated and optimised in real time rather than served from static templates.

This article introduces the RL playground, explains the core math, and applies it to the question of what web interfaces might look like when driven by continuous policy gradient agents.

## Key Topics / Sections

- **An Interactive Playground to Teach the Math**: The Deep RL sandbox — configurable environments, policy gradient visualisation, and reward curve tracking. Designed to make continuous action space RL intuitive through manipulation.
- **Inside the Interactive Simulator**: Step-by-step walkthrough of the policy gradient update — state encoding, action sampling, reward signal, and weight update. The bicycle analogy applied to each step.
- **Taking it Further — Applying This Math to the Web**: "Liquid Synthesis" — the idea that a policy gradient agent could replace static asset selectors with continuous real-time optimisation of content presentation, layout, and personalisation.
- **Comparing the Paradigms**: Traditional web delivery (deterministic templates) vs. ML-driven personalisation (supervised classifiers) vs. RL-driven synthesis (continuous optimisation toward a reward signal).

## Key Takeaways

- Continuous action space RL is fundamentally different from discrete Q-learning — the bicycle analogy captures the intuition that simpler discrete analogies miss
- Liquid Synthesis is speculative but mathematically grounded — real-time RL-driven web generation requires solving the latency and reward definition problems first
- Policy gradient methods are the connection between RL theory and LLM RLHF — understanding one gives intuition for the other
