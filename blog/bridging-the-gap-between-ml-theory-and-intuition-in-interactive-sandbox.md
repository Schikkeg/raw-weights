# Bridging the Gap Between ML Theory and Intuition: An Interactive Sandbox

> How interactive sandboxes close the gap between reading about gradient descent and actually understanding it — with hands-on playgrounds, a visual cheat sheet, and domain-specific ML applications.

## Overview

Theory without intuition is brittle knowledge. This article argues that the most effective path through ML fundamentals runs through interactive experimentation — adjusting learning rates and watching loss curves move, not just memorising equations. The RawWeights interactive sandbox approach is explained here: why it was built, how it maps to established ML curricula, and how domain-specific framing makes the concepts stick.

## Key Topics / Sections

- **Hands-On Playgrounds**: Links and context for the interactive ML tools — gradient descent visualiser, neural network weight explorer, and the Transformer playground — with guidance on what to experiment with first.
- **An Interactive Cheat Sheet**: Visual reference covering the core ML concepts in a scannable format — loss functions, optimisers, regularisation, and activation functions — built for practitioners who need a quick reference alongside the playgrounds.
- **Standing on the Shoulders of Giants**: The ML curricula and textbooks that informed the sandbox design (Andrew Ng, Andrej Karpathy, fast.ai) and how the interactive approach complements rather than replaces them.
- **Your Data, Your Industry**: Guidance on applying the generic sandbox concepts to domain-specific problems — the translation layer from "here's how gradient descent works" to "here's how it applies to my healthcare/fintech/retail dataset."

## Key Takeaways

- Intuition for ML concepts comes from manipulation, not memorisation — changing hyperparameters and observing effects builds a mental model that equations alone cannot
- The most effective sandbox designs make failure instructive: a diverging loss curve teaches more than a converging one
