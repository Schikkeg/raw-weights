5 Field Notes

Things we figured out while building.

From real implementation, not the spec.

🛡️

Always check if (document.modelContext) first

WebMCP is a Chrome origin trial — only 0.5% of global traffic can use it before Google disables the experiment. 1–5% of users are intentionally excluded as holdbacks. Your code must fall back gracefully. If the API isn’t there, your site still works — just without the AI tools. Never assume it exists.

✍️

Your tool description is the AI’s instruction manual

Early version said: “Returns navigation links.” AI agents dumped raw JSON at the user. Rewritten as: “Scan links[].desc for keywords matching the user’s question, return the matching URL as a clickable link.” — agents instantly changed behavior. The description isn’t documentation. It’s the prompt that runs every time the tool is called.

📦

Add a message field — not just structured data

Some agents echo tool results verbatim instead of formatting them. Return both: structured JSON and a pre-formatted Markdown string in a message field. Even the dumbest agent then outputs readable links. The best agents use the structure. The rest use the message. Nobody gets raw JSON.

📝

Standard fields need no schema. Custom fields do.

AI agents already know what name, email, tel, and date inputs mean — they’re universal. Define inputSchema only for fields the agent couldn’t guess: CRM dropdowns (Job_Level__c, industry_vertical), dependent selects, non-standard labels. Over-describing standard fields adds noise to the tool context and slows the agent down. Describe only what’s unusual.

⚡

Flag auto-populated fields — and pace your typing for reCAPTCHA

If a field fills itself (city from zip code, country from locale), say so in the schema: “Country auto-populates from zip — do not set directly.” If the agent tries to override it, the page’s own logic may wipe the value mid-form. For reCAPTCHA: the score is based on keystroke rhythm, mouse entropy, and hover timing — type character-by-character at human speed (35–75ms per key), hover over the submit button before clicking to allow reCAPTCHA’s token to generate, then submit. Programmatic instant-fill gets a bot score of 0.0 every time.
